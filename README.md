# УгаБугаБандрыха — «Побег от Бандрыхи»

Хоррор-выживание от первого лица на Unity. Вы заперты в Бэкрумсах, а по коридорам бродит Бандрыха. Увидит — догонит.

## Управление

| Клавиша | Действие |
|---|---|
| WASD | движение |
| Shift | бег (тратит выносливость) |
| Space | прыжок |
| Мышь | обзор |
| F | фонарик |

## Как запустить

1. Установите **Unity 6000.6.9f1** (через Unity Hub).
2. Откройте папку проекта в Unity Hub → *Add project from disk*.
3. Откройте сцену `Assets/Scenes/SampleScene.unity` и нажмите **Play**.

При первом открытии Unity соберёт папку `Library` — это займёт несколько минут.

## Что внутри

- `Assets/Scripts/PlayerController.cs` — игрок: ходьба, бег с выносливостью, прыжок, фонарик.
- `Assets/Scripts/BandrychaAI.cs` — Бандрыха: патруль, погоня при виде игрока (15 м), скример при поимке.
- `Assets/Scripts/RuntimeNavMeshBaker.cs` — строит NavMesh при запуске сцены.
- `Assets/Scripts/GameOverScreen.cs` — экран «ТЕБЯ ПОЙМАЛА БАНДРЫХА!» с перезапуском.
